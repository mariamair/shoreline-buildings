Shoreline Buildings API

This application holds data about shoreline buildings in Sweden. It contains the number of shoreline buildings per region, building type, shoreline type, area type and year.

It exposes a GraphQL API to search for the data.

Links

URL for querying the API: https://cu3156.camp.lnu.se/api/graphql

URL for using the authentication API: https://cu3156.camp.lnu.se/api/auth

Playground to test the API

Description of the data

Field Description Types Note
id The current item's id.
region The current item's region, specified with region code, name and region type.
  • sverige
  • län
  • kommun
buildingType The current item's building type, specified with id and name.
  • bostad
  • industri
  • samhällsfunktion
  • verksamhet
  • ekonomibyggndad
  • komplementbyggnad
  • övrig byggnad
  • totalt
shorelineType The current item's shoreline type, specified with id and name.
  • hav
  • inlandsvatten
  • totalt
 The numbers for "hav" and "inlandsvatten" will not add upp to "totalt".
areaType The current item's area type, specified with id and name.
  • inom tätort
  • inom formellt skyddad natur
  • totalt
 The numbers for "inom tätort" and "inom formellt skyddad natur" will not add upp to "totalt".
year The year the current item's building count applies to.
buildingCount The number of shoreline buildings.
createdAt Date and time for when the item was created.
updatedAt Date and time for when the item was updated.

Data source

Data used: Byggnader i strandnära läge efter region och byggnadstyp. År 2018 - 2023 (Shoreline buildings by region and type of building. Year 2018 - 2023)

Source: Statistics Sweden
